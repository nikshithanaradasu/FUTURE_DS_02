FUTURE_DS_02 - Customer Retention & Churn Analysis

Objective

Analyze customer churn patterns and retention trends.

Tools Used

MS Excel (Pivot Tables & Charts)

Analysis Performed

- Churn rate calculation
- Subscription-wise churn comparison
- Customer lifetime analysis

Insights

- Basic plan has highest churn rate
- Premium users have better retention
- Customers with shorter lifetime churn more

Recommendations

- Improve basic plan features
- Offer retention discounts
- Focus on long-term customer engagement
